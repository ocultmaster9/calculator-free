Como calcular o GPA na escala 4.0

O GPA (Média de Pontos de Notas) é calculado multiplicando os pontos de cada disciplina pelos seus créditos, somando todos os pontos e dividindo pelo total de créditos: GPA = Σ(pontos × créditos) / Σ créditos.

Escala padrão: A = 4,0, A− = 3,7, B+ = 3,3, B = 3,0, B− = 2,7, C+ = 2,3, C = 2,0, C− = 1,7, D = 1,0, F = 0,0.

Exemplo: Biologia (4 créditos, A = 4,0) + Química (3 créditos, B+ = 3,3) + Inglês (3 créditos, A− = 3,7): Pontos = (4×4,0) + (3×3,3) + (3×3,7) = 16 + 9,9 + 11,1 = 37,0. Créditos = 10. GPA = 37,0 / 10 = 3,70.

Perguntas frequentes

O que é um bom GPA?+
3,5+ (A−) é normalmente considerado excelente. 3,0–3,49 (média B) é bom. 2,0 (média C) é o mínimo para permanecer em situação acadêmica regular na maioria das instituições. Programas de pós-graduação costumam exigir 3,0+ para admissão; os mais concorridos podem exigir 3,5+.
O que é um bom GPA?+
3,5+ (A−) é considerado excelente. 3,0–3,49 (média B) é bom. 2,0 (média C) é o mínimo para manter boa situação acadêmica na maioria das escolas.
Como aumento meu GPA?+
Disciplinas com mais créditos têm mais impacto. Refazer disciplinas com notas baixas (se permitido) substitui a nota anterior. Trabalho consistente com A−/A em semestres futuros elevará gradualmente o GPA acumulado.
Qual é a diferença entre GPA ponderado e não ponderado?+
O GPA não ponderado usa a escala padrão 4,0. O ponderado dá pontos extras por cursos avançados (AP, IB). Esta calculadora usa a escala não ponderada.

Como o GPA é calculado

O GPA (média de notas) é uma média ponderada por créditos: multiplique os pontos da nota de cada disciplina (A = 4,0, B = 3,0, C = 2,0, D = 1,0, F = 0 na escala americana comum) pelas horas de crédito, some os resultados e divida pelo total de créditos.

Exemplo prático

Um A em uma disciplina de 4 créditos (16 pontos), um B+ em uma de 3 créditos (9,9) e um C em um laboratório de 2 créditos (4,0) dão 29,9 pontos em 9 créditos — um GPA de 3,32.

Perguntas frequentes

Ponderado ou não ponderado? Escalas ponderadas concedem pontos extras para disciplinas de honras/AP (muitas vezes até 5,0); as universidades frequentemente recalculam na própria escala.

Disciplinas de aprovação/reprovação contam? Normalmente excluídas do GPA, mas contadas nos créditos obtidos.

Como aumentar o GPA rapidamente? No começo, cada disciplina mexe muito na média; depois, refazer disciplinas reprovadas com muitos créditos tem o maior efeito, onde existem políticas de substituição de nota.
