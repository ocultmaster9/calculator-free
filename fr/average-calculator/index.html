Moyenne, médiane, mode et écart type expliqués

Il existe trois mesures courantes de la « moyenne », et chacune raconte une histoire différente sur vos données :

  • Moyenne : Somme de toutes les valeurs divisée par leur nombre. Idéale pour des données symétriques sans valeurs extrêmes. Exemple : [10, 20, 30] → moyenne = 20.
  • Médiane : La valeur centrale une fois les données triées. Préférable à la moyenne en présence de valeurs extrêmes. Exemple : [10, 20, 100] → médiane = 20 (alors que la moyenne, 43,3, est faussée par le 100).
  • Mode : La valeur la plus fréquente. Utile pour les données catégorielles. Exemple : [1, 2, 2, 3, 4] → mode = 2.

Écart type mesure la dispersion des valeurs autour de la moyenne. Un écart type faible signifie que les valeurs sont resserrées autour de la moyenne ; un écart type élevé qu'elles sont très dispersées. Pour la série [10, 20, 30] : moyenne = 20, écart type = 8,16.

Questions fréquentes

Quand faut-il préférer la médiane à la moyenne ?+
Utilisez la médiane lorsque vos données comportent des valeurs extrêmes ou sont asymétriques. Pour le revenu des ménages, par exemple, la médiane est plus parlante que la moyenne : quelques milliardaires tirent la moyenne vers le haut alors que la plupart des gens gagnent bien moins.
À quoi sert l'écart type ?+
L'écart type mesure la dispersion des données. En finance, il mesure la volatilité d'un placement. Dans les tests, il indique si les scores s'écartent nettement de la moyenne. Dans une distribution normale, environ 68 % des valeurs se situent à moins d'un écart type de la moyenne.
Quelle différence entre écart type de population et d'échantillon ?+
L'écart type de population (σ) divise par n, celui d'échantillon (s) par n−1. Utilisez le premier lorsque vous disposez des données de tout le groupe, le second lorsque vos données ne sont qu'un échantillon d'un ensemble plus vaste.
Qu'est-ce que l'étendue ?+
L'étendue est la mesure de dispersion la plus simple : valeur maximale moins valeur minimale. Pour [5, 10, 15, 20] : étendue = 20 − 5 = 15. Elle est sensible aux valeurs extrêmes mais facile à comprendre.

Moyenne, médiane et mode expliqués

La moyenne arithmétique additionne toutes les valeurs et divise par leur nombre. La médiane est la valeur centrale une fois les données triées (moyenne des deux valeurs centrales si l'effectif est pair), et le mode la valeur la plus fréquente. Chacune raconte une histoire différente sur vos données.

Exemple chiffré

Pour la série 4, 7, 7, 10, 52 : la moyenne vaut 16, la médiane 7 et le mode 7. La seule valeur extrême (52) tire la moyenne bien au-dessus de la valeur typique – c'est pourquoi les prix de l'immobilier et les revenus sont généralement publiés en médiane.

Questions fréquentes

Quand utiliser une moyenne pondérée ? Lorsque les valeurs n'ont pas le même poids : notes pondérées par les crédits, rendements pondérés par la taille des positions.

Et la moyenne géométrique ? Elle s'impose pour les taux de croissance : la moyenne géométrique de +50 % et −50 % traduit correctement une perte, là où la moyenne arithmétique affiche trompeusement 0 %.
