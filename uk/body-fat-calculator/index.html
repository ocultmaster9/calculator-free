Як Виміряти Відсоток Жиру в Тілі

Цей калькулятор використовує формулу жиру в тілі Військово-морського флоту США — один з найпрактичніших методів оцінки жиру в тілі вдома. Формулу розробили Годждон та Бекетт у Дослідницькому центрі здоров'я ВМФ, і вона використовується армією США для стандартів фізичної форми.

Формула для Чоловіків: Відсоток Жиру в Тілі = 86,010 × log₁₀(талія − шия) − 70,041 × log₁₀(зріст) + 36,76
Формула для Жінок: Відсоток Жиру в Тілі = 163,205 × log₁₀(талія + стегна − шия) − 97,684 × log₁₀(зріст) − 78,387

Усі виміри в найвужчому/найширшому місці: талія в найвужчому місці (вище пупка для чоловіків, на рівні пупка для жінок), шия одразу під адамовим яблуком, стегна в найширшому місці (тільки для жінок). Формула має похибку ±3-4% порівняно з DEXA-скануваннями.

Категорії Відсотка Жиру в Тілі (ACE)

  • Необхідний Жир: Чоловіки 2–5%, жінки 10–13% — мінімум для фізіологічного функціонування
  • Спортсмени: Чоловіки 6–13%, жінки 14–20% — худорляві, орієнтовані на результативність
  • Фітнес: Чоловіки 14–17%, жінки 21–24% — вище середньої фізичної форми
  • Середнє: Чоловіки 18–24%, жінки 25–31% — прийнятний діапазон здоров'я
  • Ожиріння: Чоловіки 25%+, жінки 32%+ — підвищений ризик для здоров'я

Часті питання

Який здоровий відсоток жиру в тілі?+
Для чоловіків 14–17% — це рівень фітнесу, а 18–24% — середній/прийнятний. Для жінок 21–24% — це рівень фітнесу, а 25–31% — середній. Нижче необхідного рівня жиру (чоловіки нижче 5%, жінки нижче 13%) існує серйозний ризик для здоров'я. Спортсмени зазвичай перебувають у діапазоні 6–13% (чоловіки) та 14–20% (жінки).
Наскільки точна формула ВМФ?+
Формула Військово-морського флоту США має похибку приблизно ±3-4% порівняно з DEXA-скануваннями (які вважаються золотим стандартом). Ця формула значно точніша за ІМТ для оцінки складу тіла. Для найкращих результатів вимірюйте тричі та беріть середнє, завжди в один і той же час доби.
Як мені правильно виміряти?+
Виміряйте талію в найвужчому місці (для чоловіків: одразу над пупком; для жінок: на рівні пупка). Виміряйте шию одразу під адамовим яблуком, тримайте стрічку щільно, але не занадто туго. Жінки вимірюють стегна в найширшому місці. Робіть всі виміри в сантиметрах або всі в дюймах — не змішуйте одиниці.
Що краще за ІМТ для складу тіла?+
Методи відсотка жиру в тілі — формула ВМФ, каліпер шкірної складки, біоелектричний імпеданс — усі більш інформативні за ІМТ, оскільки розрізняють жирову масу від безжирової. DEXA-сканування — золотий стандарт. Гідростатичне зважування та Bod Pod (плетизмографія витіснення повітря) обидва дуже точні.

Оцінка Відсотка Жиру в Тілі

Метод Військово-морського флоту США оцінює жир у тілі за вимірами обхвату — шия та талія для чоловіків; шия, талія та стегна для жінок — у поєднанні зі зростом за логарифмічними формулами. Потрібна лише сантиметрова стрічка, і він послідовно відстежує зміни з часом.

Приклад Розв'язання

Чоловік зростом 180 см з талією 90 см та шиєю 38 см має приблизно 20% жиру в тілі. Діапазони Американської ради з фізичних вправ: необхідний жир 2–5% (чоловіки) / 10–13% (жінки); спортсмени 6–13% / 14–20%; середнє 18–24% / 25–31%.

Часті питання

Наскільки точний метод стрічки? Для більшості людей у межах ±3-4% від лабораторних методів — вимірюйте в один і той же час доби, стрічка щільно, але не занадто стиснута.

Чому жир у тілі важливіший за вагу? Дві людини з однаковою вагою можуть мати дуже різний склад; ризик для здоров'я краще відстежує вісцеральний жир, ніж просто цифра на вазі.
