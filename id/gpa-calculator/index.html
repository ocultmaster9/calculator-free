Cara Menghitung GPA pada Skala 4,0

GPA (rata-rata nilai) dihitung dengan mengalikan poin nilai tiap mata kuliah dengan jumlah SKS-nya, menjumlahkan seluruh poin nilai, lalu membaginya dengan total SKS. Rumus: GPA = Σ(poin nilai × SKS) / Σ SKS.

Skala standar 4,0: A+ = 4,0, A = 4,0, A− = 3,7, B+ = 3,3, B = 3,0, B− = 2,7, C+ = 2,3, C = 2,0, C− = 1,7, D+ = 1,3, D = 1,0, D− = 0,7, F = 0,0.

Contoh: Biologi (4 SKS, A = 4,0) + Kimia (3 SKS, B+ = 3,3) + Bahasa Inggris (3 SKS, A− = 3,7): Poin = (4×4,0) + (3×3,3) + (3×3,7) = 16 + 9,9 + 11,1 = 37,0. SKS = 10. GPA = 37,0 / 10 = 3,70.

Pertanyaan Umum

Berapa GPA yang tergolong baik?+
3,5 ke atas (A−) umumnya dianggap sangat baik. 3,0–3,49 (rata-rata B) tergolong baik. 2,0 (rata-rata C) adalah batas minimum untuk tetap berstatus akademik baik di sebagian besar kampus. Program pascasarjana sering mensyaratkan 3,0 ke atas; program terbaik bisa meminta 3,5 ke atas.
Apa beda GPA berbobot dan tanpa bobot?+
GPA tanpa bobot memakai skala standar 4,0 untuk semua mata kuliah. GPA berbobot memberi poin tambahan untuk kelas honors, AP, atau IB (biasanya +0,5 untuk honors dan +1,0 untuk AP/IB). Kalkulator ini memakai skala 4,0 tanpa bobot.
Bagaimana menaikkan GPA saya?+
Mata kuliah dengan SKS lebih besar berdampak lebih besar. Mengulang mata kuliah bernilai rendah (jika diizinkan) menggantikan nilai lama. Hasil konsisten A− hingga A pada semester berikutnya akan menaikkan IPK kumulatif Anda secara bertahap. Nilai-nilai awal paling berpengaruh karena punya waktu lebih panjang untuk berdampak.
GPA berapa yang saya butuhkan untuk pascasarjana?+
Sebagian besar program pascasarjana mensyaratkan GPA minimal 3,0. Program MBA terbaik biasanya lebih memilih 3,5 ke atas. Fakultas kedokteran mencari 3,5 ke atas. Sebagian program STEM lebih menimbang skor GRE dan pengalaman riset daripada GPA.
